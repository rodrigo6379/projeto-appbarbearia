# DOM MEN

Sistema de gerenciamento para barbearias.

## Funcionalidades
- Dashboard com indicadores.
- Gerenciamento de agendamentos.
- Controle financeiro.
- Cadastro e gerenciamento de serviços.
- Registro de receitas e despesas.

## Tecnologias
- React
- TypeScript
- Vite
- Tailwind CSS
- Banco de dados

## Objetivo
Facilitar a administração de barbearias por meio de uma plataforma moderna, organizada e responsiva.
